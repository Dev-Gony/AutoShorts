# AutoShorts MVP PRD

## 목표
블로그 URL을 입력받아 1분 이내 세로형 숏폼 영상을 자동 생성한다.

## 성공 기준
- URL 입력 이후 사용자 개입 0회
- 1080x1920 MP4
- 영상 길이 60초 미만
- 전체 처리 시간 3분 이내

## 파이프라인
URL 검증 → 본문 추출 → 텍스트 정제 → 숏폼 대본 생성 → TTS → 타임스탬프 전사 → 자막 → 배경 영상 합성 → MP4

## MVP 포함
- 네이버 블로그
- 티스토리
- 일반 HTML 블로그
- OpenAI 기반 대본 생성
- TTS
- 타임스탬프 기반 자막
- 준비된 배경 영상 루프
- 단계별 검증과 로깅

## MVP 제외
- SNS 자동 업로드
- AI 영상/이미지 생성
- BGM 추천
- 회원가입/DB/결제
- 클라우드 배포

## 품질 기준
- 본문 100자 미만이면 실패
- 대본 권장 280~380자, 최대 420자
- 목표 음성 45~58초
- 59초 초과 시 향후 자동 축약 루프 적용
